# Marketing Analytics & Uplift Modeling

Оптимизация маркетинговых инвестиций и измерение эффекта воздействий.

## Проекты

| Проект | Задача |
|--------|--------|
| [marketing_mix_modeling_mmm](./marketing_mix_modeling_mmm) | Оценка вклада маркетинговых каналов в продажи |
| [uplift_tree](./uplift_tree) | Uplift-моделирование для таргетирования акций |
| [gmroi_optimization](./gmroi_optimization) | Оптимизация GMROI (валовой рентабельности инвестиций) |
| [smart_link_i_epsilon_greedy](./smart_link_i_epsilon_greedy) | Epsilon-greedy стратегия для смарт-ссылок |
| [dead_ad_alert](./dead_ad_alert) | Детекция неработающих рекламных креативов |
| [asymmetric_metrics](./asymmetric_metrics) | Асимметричные метрики для оценки кампаний |
