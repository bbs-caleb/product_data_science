# Product Card Validator

Цель: проверить карточки товаров на:
- обязательные поля (name, brand, barcode, category, units, etc.)
- типы/форматы (числа, строки, допустимые значения)
- дубликаты (barcode, нормализованное имя+бренд, etc.)
- отчёт: список ошибок + агрегаты по типам проблем

Выход: таблица issues + краткая сводка (для Excel/Power BI).
