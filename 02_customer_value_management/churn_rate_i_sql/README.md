# Churn Rate Prediction

Построение модели оттока пользователей образовательной платформы.

## Задача

Выявить пользователей с высоким риском оттока на основе их активности: частоты решения задач, паттернов поведения и динамики вовлечённости.

## Данные

Источник: ClickHouse, таблица `default.churn_submits`

| Поле | Описание |
|------|----------|
| timestamp | Время попытки |
| user_id | ID пользователя |
| task_id | ID задачи |
| submit | Номер попытки |
| score | Полученный балл |
| is_solved | Успешность решения |

## Этапы

**I. Data Aggregation & Feature Engineering**
- Сбор данных об активности (SQL, оконные функции)
- Recently-Frequency Analysis
- Обучение и оптимизация модели

**II. Model Validation**
- Доверительный интервал для ROC-AUC
- Подбор порога классификации

**III. Deployment**
- Docker-контейнеризация
- Uplift-моделирование

## Стек

`SQL` `ClickHouse` `Python` `Docker`
