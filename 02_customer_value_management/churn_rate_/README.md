# Churn Rate Prediction: модель прогнозирования оттока пользователей 

## Задача

Выявить пользователей с высоким риском прекращения активности в ближайшие 14 дней на основе поведенческих паттернов.

## Подход

### 1. Data Aggregation -- done
- Построение user-day матрицы активности
- Заполнение пропущенных дней (negatives mining)

### 2. Feature Engineering -- done
RFM-анализ через оконные функции:
- `days_offline` - дней с последней активности
- `avg_submits_Nd` - средняя активность за N дней
- `success_rate_Nd` - доля успешных решений
- `solved_total` —- накопленный прогресс

### 3. Modeling -- пока тут
- Валидация
- Нужно оценить логрег
- Встроить в SQL-запрос

## Метрика

**ROC-AUC ≥ 0.9** на дату прогноза 2022-11-19
